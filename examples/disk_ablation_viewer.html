Interpretation and limits

What “leaf-local” means here

Local centroids and PCA bases are fitted using only the new batch's points in one current leaf. Their parameters then freeze. Append layout may leave those historical groups scattered across descendant leaves. Leaf layout copies the required frozen decoder with each relocated frame, so each block is independently readable. Neither layout requantizes or reprojects historical vectors.

Information gain is a synthetic proxy
FormatChoice agreementRegret, bitsMean cosine distortionTie-aware recall

These 64 trials per seed reuse the existing binary entropy and inverse-distance response functions. Hypotheses and priors remain fixed; only candidate representations change. The distance is cosine-derived, not a Fermat-path calculation. These are not human relevance or preference-learning measurements.

Crash recovery, expiry and remaining engineering work

Payload files are fsynced before SQLite publishes their references. Tests abruptly terminate processes around publication and reopen the store. Synthetic runs exercise daily payload reclamation, edits, duplicate replay and deletion. Identity tombstones and reusable SQLite free pages are retained in this prototype; a bounded metadata-history and vacuum policy is still needed for a long-running service.

The store is a single-owner local-disk prototype. It has no concurrent query service, production schema migration, network storage support or deployed encoder switch. Leaf states use trusted local Julia serialization and require the pinned Julia version for continuation.

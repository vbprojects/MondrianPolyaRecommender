Measured on held-out posts

Values are means across three clustering seeds; hover for the range. ARI is agreement with hidden topics, adjusted for chance (0 ≈ chance, 1 = identical). Balanced accuracy uses training-only group-majority labels. Topic P@10 measures how many of ten retrieved posts share the query’s hidden topic, averaged equally over the six topics. Missing results count as misses.

Neighbor recall@10 is the fraction of the model’s exact ten nearest training posts found inside one partition. Candidate % is the fraction of training posts in that partition. Searching additional partitions can improve recall. Silhouette uses cosine distances within each model’s own space; it is not an independent measure of semantic quality.

What this experiment establishes

EncoderDimensionsGPU seconds / 1,000Embedding storage / million

Warm median of three runs on the same 1,000 texts, batch size 64, tokenization + synchronous ONNX inference + normalization and output copies; excludes model loading/download. Native exports: current Model2Vec uses its existing mixed/FP16 graph; Arctic uses the official unquantized export. Raw storage is Float32 payload only, before the project’s post codec.

The topic probe uses weak hashtag labels, not human relevance judgments. All hashtags are stripped from probe inputs; authors and normalized exact text do not cross train/test within a cohort. Near-duplicate templates, ordinary topic words, language differences and URLs can still matter. The corpus has no reliable language labels, so this is not a language-controlled benchmark. No likes, user feedback, Fermat-distance sampling, decay, or online engagement outcomes are evaluated.

The adaptive tree uses its existing random axis-aligned cuts and leaf-local rank-4 PPCA. PPCA estimates density inside each leaf; it does not optimize cut placement for topics. Native dimensions and matched leaf budgets are compared, so this measures the full encoder choice, not architecture in isolation. K-means is a batch, cosine-optimized diagnostic baseline.

The natural sample comes from the existing bounded historical archive, not a random sample of all Bluesky. PCA is fitted on training vectors separately for each encoder; axes, colors and numeric group IDs do not correspond between panels. Overlap in these plots does not prove overlap in the original embedding space.

Collapse score: training-only balanced accuracy of each original pixel cut when evaluated on the PCA reconstruction. A subtree collapses only if every active internal cut in it scores below the selected threshold. Weak ancestors are retained when needed to reach stronger descendants. All retained assignments preserve original ancestry, but groups can still overlap in projection. This is one explicit pruning heuristic, not an optimized 2D classifier.

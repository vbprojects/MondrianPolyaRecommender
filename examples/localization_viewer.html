The likelihood is 0.05 + 0.90 / (1 + distance / scale). Location success uses a Fermat-radius ball, not exact equality of points. Candidate posts and hidden positions are quantized to the grid. The dense-region prior and response model are known correctly in this experiment. Path proposals sample four competing branch pairs, select graph vertices at weighted path fractions, and snap them to available posts. Midpoint-only tests symmetry; asymmetric probes include endpoints and 20/35/50/65/80% positions. Shared distance, predecessor and nearest-post caches are precomputed. A confidence threshold is not guaranteed empirical accuracy on every finite batch.

The shown trial is the first preselected target, not a selected success. Playback continues beyond the first stop for diagnosis. No movement, decay, niche-user test, or text embeddings. A “timeframe” is a maximum number of responses; no human response latency is assumed. Summary · Trial data

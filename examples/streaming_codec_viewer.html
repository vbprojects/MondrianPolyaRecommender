What this establishes

All methods use the same decayed rank-four density tree and receive only their current input batch. Historical originals are reserved for audits. Frozen codecs retain their original local decoders; the sequential control repeatedly reprojects old codes. Inherited bases share immutable directions and add up to four innovations at a time, capped at rank 16.

Midpoint queries average two real posts in the same true leaf. Retrieval is scored against original-coordinate Euclidean neighbors. The information-gain test uses a synthetic response model and fixed hypotheses. These measurements do not establish human recommendation quality or evaluate Fermat-path proposals.

Binary payload and Julia object memory are different measurements. Text, the external post catalog, audit arrays, viewer history and temporary encoding workspaces are excluded. The table reports measured single-thread CPU codec timings, including allocation and GC; it is not a production throughput benchmark.

What changed

Cut locations depend on reservoir geometry and arrival counts, so they can be planned without PPCA updates. The numerical pass then processes regions in dependency order, preserving each region’s observation order and transferring moments before its children run. Buffers persist between launches; each tree level exchanges packed state. Cooperating GPU threads handle embedding coordinates, with a register-based 2D specialization.

This is the optimized whole-batch fit API. Intermediate callbacks and custom external eigensolvers still use the original event driver; those modes are not represented by these speedups. No cut thresholds, ranks or decay parameters were relaxed. Model statistics remain Float64. No claim is made that every possible stream is faster.

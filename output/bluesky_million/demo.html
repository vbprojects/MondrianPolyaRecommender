Interpretation and limits

One Gaussian per active leaf. At a cut the parent is replaced by two conditional-moment approximations. Internal nodes retain routing geometry but no PPCA model or reservoir. Rank is four, reservoir capacity is 64 per leaf, and splitting requires 512 arrivals since leaf creation. Limits: 10,000 leaves and depth 24. The cut axis uses reservoir coordinate ranges; thresholds lie between its quartiles. This is a data-adaptive Mondrian-style heuristic, not an exact Mondrian process.

Tree memory is Julia reachable-object size. It excludes the input archive, runtime, allocation garbage, tracking records and per-post IDs/codes. Process RSS includes the memory-mapped input pages and Julia runtime. These are different measurements, not alternative estimates of the same storage. State and reservoir breakdowns have small separate container overheads.

One million unique-URI, nonblank posts sampled from the first 60,000 records in each of 20 pinned dataset shards, then ingested in seed-192 random order. This is not a chronological day or a corpus-wide uniform sample. GPU computes embeddings; the tree fits on CPU. Gaussian moment transfer ignores inherited box truncation; retained mass is conserved but historical leaf assignment is approximate. No recommendation quality claim follows from this scaling run.
